# Vector Studio — ویرایشگر وکتور برای اندروید

برنامه‌ی ترسیم وکتور به سبک ایلوستریتور (قلم، ویرایش نقاط، لایه‌ها، گرادیان، چیدمان…) با خروجی **AI / PDF / SVG / PNG**.
کل برنامه آفلاین است و داخل یک WebView اجرا می‌شود (فایل `app/src/main/assets/index.html`).

## ساخت فایل APK

### راه ۱ — بدون نصب هیچ‌چیز (GitHub Actions) ✅ پیشنهادی
1. در github.com یک حساب و یک مخزن (Repository) جدید بسازید.
2. همه‌ی محتوای این پوشه (از جمله پوشه‌ی مخفی `.github`) را در مخزن آپلود کنید (از کامپیوتر: Add file ← Upload files، پوشه را بکشید و رها کنید).
3. تب **Actions** را باز کنید؛ ساخت به‌طور خودکار شروع می‌شود (حدود ۳–۵ دقیقه).
4. بعد از پایان:
   - از بخش **Releases** ← `VectorStudio.apk` را مستقیم روی گوشی دانلود کنید، یا
   - از همان صفحه‌ی Actions بخش Artifacts را دانلود و از حالت zip خارج کنید.
5. روی گوشی APK را باز کنید و اگر خواست، «نصب از منابع ناشناس» را برای مرورگر/مدیر فایل فعال کنید.

### راه ۲ — Android Studio
پوشه را با Android Studio باز کنید ← صبر کنید Gradle Sync تمام شود ← منوی `Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)`.
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

### راه ۳ — خط فرمان
با JDK 17 و Android SDK (API 34): `gradle assembleDebug`

## کار با برنامه
- **دو انگشت**: زوم و جابه‌جایی بوم (همیشه فعال). ابزار «دست» برای جابه‌جایی با یک انگشت.
- **قلم (Pen)**: لمس = نقطه‌ی گوشه‌ای · لمس و کشیدن = نقطه‌ی نرم با دسته‌های بزیه · لمس نقطه‌ی اول = بستن مسیر · دکمه‌ی «✓ پایان مسیر» برای مسیر باز.
- **مستقیم (Direct Selection)**: ویرایش نقاط و دسته‌ها؛ کشیدن روی بخشی از منحنی = تغییر شکل همان قطعه؛ کشیدن در فضای خالی = انتخاب چند نقطه.
- **افزودن/حذف/تبدیل نقطه**: روی مسیر انتخاب‌شده لمس کنید (تبدیل: لمس = نرم↔گوشه، کشیدن = ساخت دسته).
- **مداد**: ترسیم آزاد با هموارسازی خودکار؛ اگر نزدیک نقطه‌ی شروع تمام کنید مسیر بسته می‌شود.
- **شکل‌ها**: خط، مستطیل (با گردی گوشه)، بیضی، چندضلعی، ستاره — بکشید یا فقط لمس کنید.
- **نوار «چندانتخابی / قید / چسبیدن»** بالای ابزارها: معادل Shift و Snap در ایلوستریتور.
- **پنل‌ها**: سبک (رنگ، گرادیان، ضخامت، سر خط، گوشه، خط‌چین، شفافیت، متن) · لایه‌ها · چیدمان (Align / Distribute / Arrange / Group / Compound) · تبدیل (X, Y, W, H, چرخش، مقیاس، قرینه) · صفحه (اندازه‌ی بوم، شبکه) · خروجی.
- پروژه خودکار ذخیره می‌شود؛ با «ذخیره پروژه» می‌توانید فایل JSON بگیرید.
- فایل‌های خروجی در `Downloads/VectorStudio` ذخیره می‌شوند.

## نکات و محدودیت‌های شفاف
- فایل **AI** همان ساختار PDF-سازگار است (مثل خود ایلوستریتور) با پسوند `.ai`؛ ایلوستریتور آن را باز می‌کند و مسیرها قابل ویرایش‌اند. داده‌ی اختصاصی ایلوستریتور (مثل Live Effects) در آن نیست.
- متن‌های **لاتین** در PDF/AI متن واقعی می‌مانند؛ متن **فارسی/عربی** چون فونتی داخل فایل جاسازی نمی‌شود، به‌صورت تصویر شفاف با کیفیت بالا قرار می‌گیرد (در SVG/PNG همیشه کامل است).
- فعلاً Pathfinder کامل (Union/Subtract/Intersect)، Clipping Mask، Blend و Import از AI/SVG وجود ندارد؛ Compound Path (Exclude) هست.
